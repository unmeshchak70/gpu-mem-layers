GPU Buffer Pool for Product-Key Memory Layers

Unmesh Chakravarty (ukc), Sumukh Venkatesh (sumukhv)

Summary

We are building a GPU buffer pool that lets product-key memory layers use value tables larger than GPU memory by keeping the full table in host memory and caching hot rows in device memory. Our CUDA implementation on GHC RTX 2080s combines a concurrent GPU cache with batch-level request deduplication, skew-aware replacement, and a per-batch choice between zero-copy reads and bulk transfers for missed rows. We evaluate it against an all-in-GPU table, on-demand host fetching, and CUDA Unified Memory.
